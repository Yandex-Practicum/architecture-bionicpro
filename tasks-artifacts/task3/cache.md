Отчёты хранятся в приватном бакете MinIO по ключу:
reports/<sha256(user_id)>/<date_from>_<date_to>_v<version>.json.

Версия определяется часовым интервалом. В пределах интервала API
использует готовый объект из S3 без повторных запросов к ClickHouse.
При смене версии отчёт формируется заново по первому запросу.

CDN кеширует файл по пути объекта на 10 минут. Новая версия получает
новый путь и отдельную запись кеша. Максимальная задержка обновления
отчёта после повторной обработки ETL — один час.

Старые объекты автоматически удаляются по lifecycle-правилу через
семь дней. Доступ к файлу проверяется сессионным бэкендом перед CDN.
